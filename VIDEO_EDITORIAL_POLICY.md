- Enlarge key labels, figures, and captions; remove small secondary clutter. Inspect reduced-resolution readability. A higher-resolution source does not force viewers' playback quality.

- Assign explicit highlight targets to narrated sentences/clauses. Bind each change to the actual generated audio segment. Split clauses when several products are discussed sequentially. Do not cycle boxes on a timer or estimate timing from character counts.
- Highlight the named item, multiple items for a joint comparison, and hide emphasis during unrelated caveats/general guidance. Hold emphasis only while its meaning remains relevant. Captions must match the spoken segment and target.
- Check layout overflow, encoded media duration, target selection, transition timing, and the no-highlight intervals in the finished video. Technical checks are not a claim that the user has listened.
- Retain original analysis, verified sources, clear hypothetical examples and limitations; never invent hands-on experience. Tailor each video's question and reasoning to the subject.
- Keep the natural on-screen wording “이해를 돕기 위한 연출 이미지” and all required platform/legal disclosures. Descriptions include the exact guide URL, platform-specific UTM, current chapter times, sources, and applicable affiliate notices.
- Continue mobile preview → explicit approval of the exact version/hash → requested platforms → processing/public-status verification. Keep credentials private, prevent duplicate uploads, and preserve media on unresolved posting failures. Use free/cardless services unless separately authorized.

The aim is useful, original comparisons, not a guarantee of YPP acceptance.

- Give each video its own question, evidence, tradeoffs and reasoned verdict; changing a product name inside a generic template is insufficient.
- Separate manufacturer facts, our editorial interpretation, hypothetical examples and hands-on results. Do not invent tests or experience.
- Check exact model, variant and verification date. Narrow the claim to the item actually verified.
- Explain numbers and limitations, rather than reading marketing claims as personal guarantees.
- Show relevant original tables, accurate charts and decision examples. Animation alone does not make derivative content original.
- Provide an actionable conclusion inside the video. Website links supply extra evidence and tools.
- Keep AI lifestyle scenes illustrative; use “이해를 돕기 위한 연출 이미지” on screen. Preserve legally/platform-required disclosures, including the upload disclosure for realistic synthetic scenes.
- Match source links, captions and description to the exact approved video version. Public upload requires explicit user approval.

## Guide-link placement — default publication rule, 2026-10-31

- Put the exact related website guide URL on the FIRST description line with a short, accurate benefit-led CTA, such as “👉 자세한 비교표·선택 가이드: URL”. Do not put a greeting, introduction, blank line, hashtags, chapters, or a source list above it.
- Follow with one short sentence describing the actual value in the linked article; keep the rest of the useful description, sources, chapters and disclosures below. Preserve platform-specific tracking.
- Use engaging language grounded in what the guide actually contains; do not invent discounts, exclusivity, test results or exaggerated promises.
- Aim to expose the link in the collapsed description before More. Check desktop/mobile presentation when possible; wrapping, truncation and link clickability depend on YouTube and viewer conditions, so do not guarantee identical visibility across all devices or claim a click test from API metadata alone.
- Verify the saved first line through the live video API after publishing or updating metadata. This rule concerns the description; a pinned comment is an additional separately supported placement.

## 시작 인사·브랜드·화질·구독 안내 — 2026-10-31 기본 규칙
- 향후 한국어 일반영상은 짧은 인사로 시작한다. Sarah 음성으로 “안녕하세요, 스마트 초이스 삼육오입니다. 오늘은 [이번 영상의 구체적인 주제·질문]을 이야기해 보겠습니다.”라고 자연스럽게 안내한다. 화면에는 실제 우리 로고와 공식 홈페이지 주소 smartchoice365-web.pages.dev를 잠깐 보여주고, 인사에 어울리는 브랜드 화면 또는 관련 이미지를 사용한다. 실제 출연하지 않은 인물을 실제 진행자처럼 표현하지 않는다.
- 이어서 “화면이 흐리게 보이면 설정에서 화질을 높여 주세요.”라고 말하며 톱니바퀴 → 화질 → 1080p 선택을 큰 아이콘·화살표·간단한 그림으로 안내한다. 스마트폰에서 필요한 경우 ‘고급’ 선택 단계를 포함한다. 제작 당시 확인한 YouTube 기기별 메뉴에 맞춰 표현하며 기기별 위치가 완전히 같다고 단정하지 않는다. 해당 영상에서 실제 제공되는 해상도만 안내하고, 전체 화면을 작은 설정 화면 캡처로 채우지 않는다.
- “도움 되는 구매 비교를 계속 보시려면 구독도 부탁드립니다.”처럼 짧고 부담 없는 구독 부탁을 음성과 화면으로 넣는다. MP4 속 구독/설정 그림이 실제 클릭 버튼이라고 안내하지 않는다.
- 인사 → 브랜드·주제 소개 → 화질 안내 그림 → 구독 부탁을 자연스럽게 이어 붙인다. 별도의 긴 로고 애니메이션·중복 안내·과도한 대기 시간을 넣지 않는다. 전체 도입은 가급적 약 20~25초 내외로 압축하되 실제 음성 길이와 그림을 읽을 시간을 기준으로 조절한다.
- 기존의 ‘결론을 첫 문장에’ 규칙은 이 짧은 도입 뒤 본문 첫 부분에서 유용한 판단·핵심 결론을 바로 제시하는 방식으로 변경한다. 본문의 그래프 스타일·발화별 강조 동기화는 유지한다.
- 인사·화질 안내·구독 안내도 실제 음성 구간에 맞춰 로고·그림·자막을 동기화하고, 시작 장면이 늘어난 만큼 모든 본문 강조·자막·구간 안내 시간을 다시 계산한다.
- 이번 변경은 제작 기본 규칙 저장이다. 기존 공개 영상의 MP4 변경·재제작·재업로드를 완료한 것으로 보고하지 않는다.

## 인물 사진 잘림 방지 — 2026-10-31 기본 규칙
- 인물·모델·제품의 주요 부분을 사진 틀에 맞춘 자동 확대/중앙 자르기로 없애지 않는다. 원본 종횡비를 유지해 선택한 사진 전체를 보여주는 contain 배치를 기본으로 하고, 남는 여백은 배경색으로 처리하거나 사진 틀의 크기·배치를 조정한다. 원본에 없는 신체 부위가 복원됐다고 표현하지 않는다.
- 여러 컷이 합쳐진 원본에서 명시적으로 선택한 컷을 분리할 수는 있지만, 선택한 컷 안에서는 머리·얼굴·어깨·손·의복이 추가로 잘리지 않게 한다. 자막·연출 이미지 표시·강조 상자가 인물을 가리지 않도록 별도 영역을 확보한다. 인물 사진에는 임의 줌·팬·cover 효과를 적용하지 않는다.
- 새 사진과 프레임 비율이 다를 때마다 인물 사진이 나오는 모든 장면과 최종 MP4의 실제 프레임을 확인한다. 세로 인물을 가로 틀에 넣는 경우와 여러 인물/세 컷 비교도 포함한다. 잘림·표시 겹침이 있으면 제작을 완료 처리하지 않고 배치를 수정한다. 공통 사진 배치 검사에서 원본 네 모서리 보존과 고지 영역 분리를 확인한다.
- 이번 히트텍은 hero/실내/야외 세 사진 장면을 모두 수정하고, 구형 가로·세로 렌더러에도 같은 공통 배치 함수를 적용한다. 승인 로고 원본과 대본·음성 설정·발화별 강조 원칙은 유지한다.
