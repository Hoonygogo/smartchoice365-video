1. Research exact model/variant, meaningful alternatives, dated delivered prices, card/member/coupon eligibility, displayed seller identity, returns/warranty and positive/negative reviews. Record verified facts and unknowns separately. A high rating is not seller authentication or proof of low failure rates.
2. Publish a useful standalone original comparison with an explicit buyer-specific verdict and `/recommendations/` category link. Preserve all existing SEO/analytics/branding rules. Unknown essential seller/warranty/total-price facts preclude a fully verified seller endorsement.
3. Put a genuine account-issued exact-product affiliate CTA beside a deep link to the same product's detailed recommendation reasons. Use only the issued URL; never fabricate tracking. Record observation date and competing conditional offers. No guaranteed nationwide cheapest claim.
4. Verify the public exact article, then prepare a distinct Naver companion with BOTH the direct purchase link and adjacent `왜 이 제품과 구매처를 추천할까요? 선정 이유와 상세 비교 확인하기` deep link. Naver remains manual unless the owner specifically changes that workflow. Do not claim a draft is posted.
5. For each selected product create a YouTube full comparison AND a separate vertical Short, then distribute the Short to YouTube Shorts, Facebook Reels and Instagram Reels through the EXISTING `Hoonygogo/smartchoice365-video` pipeline. Follow that repository's quality, voice, media approval/hash, encoding, disclosure and duplicate rules. No new paid services. This is the owner's explicit request to produce/distribute these selected products; do not infer permission to replace/delete older uploads.
6. Full video: explain product choice, seller choice, downsides and exception buyers. Description first line: exact live same-product recommendation article; verified affiliate URL next with the network disclosure. Short: useful problem + evidence + conditional verdict + factual CTA. Link to full video ONLY once it is publicly verified; never invent a video ID.
7. FB: actionable site and purchase links where permitted with disclosure. IG: useful caption and actual available profile-link route; never pretend caption URLs or an unset bio link are clickable. Shorts Related video must be set and verified separately. Stories need their own legible CTA and supported linking; not automatically required by this request.
8. Persist per-product per-channel states (`research`, `site`, `naver`, `fullVideo`, `shorts`, `facebook`, `instagram`), blockers, media hashes and actual published URLs. Rendered, queued, uploaded, processed and publicly verified are distinct stages. A completion claim needs verified channel receipts.
